Primer PICKR API

Access our ranked primer data programmatically.

Introduction

The Primer PICKR API provides direct access to our database of scored and ranked PCR primer pairs for multiple species. You can use our endpoints to integrate primer data into your own applications, scripts, and workflows. All endpoints return data in JSON format.

Primer Search Endpoint

GET /api/primers/

This is the main endpoint for retrieving ranked primer pairs for a specific gene and species, with optional filtering and sorting.

Parameters

Parameter Type Description
Required
gene string The official gene symbol (e.g., "TP53").
Optional Filters
species string The species to search. Options: 'human' (default), 'mouse'.
min_tm / max_tm float Min/max melting temperature (°C).
min_gc / max_gc integer Min/max GC content (%).
min_len / max_len integer Min/max primer length (bp).
min_amplicon / max_amplicon integer Min/max amplicon length (bp).
min_citations integer Minimum combined citations for the pair.
Optional Sorting
sort_by string Sort order. Options: 'score' (default), 'citations', 'amplicon'.

Example Request


curl "https://yourdomain.com/api/primers/?gene=Actb&species=mouse&sort_by=citations"

Gene Suggestions Endpoint

GET /api/gene-suggestions/

Use this endpoint to get a list of similar gene names for a specific species if an initial search yields no results.

Parameters

Parameter Type Description
query string The partial gene symbol to search for.
species string The species for the suggestions. Defaults to 'human'.

Example Request


curl "https://yourdomain.com/api/gene-suggestions/?query=Sox&species=mouse"

Example Response


[
    "Sox2",
    "Sox9",
    "Sox10",
    "Sox17"
]
